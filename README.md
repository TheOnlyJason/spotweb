# SpotWeb — Semicircular Vinyl Carousel

A Three.js gallery: vinyl records orbit around you on the front semicircle (9 o'clock → 3 o'clock). Records face inward, auto-rotate continuously.

## Run

```bash
npm install
npm run dev
```

## Stack

- Vite + Three.js
- CSS2D labels for track names
- MeshStandardMaterial, shadows, fog
